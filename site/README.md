# Static portfolio site

This directory is intended for static hosting (for example, GitHub Pages or Vercel static output). It contains a portfolio page and a fictional interactive demonstration. It has no backend and should not collect personal data.

Before deployment, verify the repository link in `index.html` points to https://github.com/kinga109/beyond-engagement. Do not deploy the FastAPI app as-is; it is a local research demonstration and explicitly not intended for public deployment.
